# Charts

Generated by `bench chart` from the committed run directories and
[docs/slo.json](../slo.json); rebuild them all with `make charts`
([scripts/charts.sh](../../scripts/charts.sh)). Each SVG records its command
in `<metadata>`, and a test regenerates every file here byte for byte, so
none is edited by hand. Filled markers are levels that meet the SLO, hollow
ones miss it; see [docs/02](../02-architecture.md#charts).

| File | Shows |
|---|---|
| [headline.svg](headline.svg) | Max compliant goodput per engine config, both profiles |
| [interactive-saturation.svg](interactive-saturation.svg) | Interactive baseline: output tok/s, TTFT p95, TPOT p95 against concurrency |
| [throughput-saturation.svg](throughput-saturation.svg) | Throughput baseline: output tok/s, E2E p95 against concurrency |
| [interactive-experiments.svg](interactive-experiments.svg) | Interactive: baseline, A, B1, B2 |
| [throughput-experiments.svg](throughput-experiments.svg) | Throughput: baseline, A, B1, B2 |
| [throughput-engine.svg](throughput-engine.svg) | Throughput: KV use, waiting requests, preemptions; baseline and B2 |
