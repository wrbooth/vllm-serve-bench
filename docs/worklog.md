# Worklog

Time-boxed take-home (4–6 h budget), worked in separate sessions rather than one
sitting. Times are wall clock, Pacific.

**How time is counted.** A session opens when the owner starts working and
closes when they step away. Only open sessions count. A sweep or download that
runs unattended while the owner is away is listed under the session that
started it, but its runtime is not added. The commit log is the cross-check:
every commit should fall inside a session, and a session with no commits needs
a note saying what it was.

The build order and the status of each deliverable live in
[wiki/project.md](../wiki/project.md). The reasons behind the decisions live in
[wiki/log.md](../wiki/log.md).
